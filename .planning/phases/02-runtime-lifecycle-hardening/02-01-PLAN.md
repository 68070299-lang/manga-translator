# Plan 02-01: Runtime Lifecycle Hardening

## Objective

Close the lifecycle risks found by the Sol review without copying Ichigo's
account or hosted-service architecture.

## Tasks

1. Replace monotonic DNR IDs with fixed CDN IDs, reconcile exact owned stale
   rules on startup, share same-CDN leases, and fall back to ordinary fetches
   on collisions or installation errors.
2. Add domain-anchored DNR conditions and regression tests for ownership,
   legacy cleanup, collisions, concurrent leases, and cleanup failures.
3. Add a disposable content runtime scope, preserve always-on blob cleanup,
   and cover disable/re-enable and storage-failure behavior.
4. Refresh action state on startup/install and add one cache recheck plus one
   transport-only content retry, preserving force-refresh and backend timeout
   semantics.
5. Run repository, build, lint, unit, integration, backend, and packaging
   verification.

## Verification

- `npm run lint`
- `npm run test:unit -- --runInBand`
- `npm run test:integration -- --runInBand`
- `npm run lint:backend`
- `npm run test:backend`
- `npm run verify:repository`
- `npm run build`
- `npm run package`
