# Plan 01-01: Shared Translation Queue

## Objective

Make the service worker share identical in-flight image translations across
tabs while keeping local work serial and cloud work capped at three jobs.

## Tasks

1. Add a small FIFO queue module with per-key promise deduplication, subscriber
   progress notifications, cleanup on resolve/reject, and configurable
   concurrency.
2. Load two queues in the service worker and route cache-keyed provider jobs to
   the local or cloud queue.
3. Preserve cache hits, force-refresh behavior, current error responses, and
   existing page-level concurrency.
4. Add tests for deduplication, concurrency, failure cleanup, and force-refresh
   separation.
