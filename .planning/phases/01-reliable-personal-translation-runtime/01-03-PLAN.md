# Plan 01-03: Protected CDN Fetching and Verification

## Objective

Improve image fetching for known hotlink-protected CDNs without accepting
arbitrary referrers or leaving persistent request rules behind.

## Tasks

1. Add fixed CDN/referrer mappings and a transient DNR session-rule wrapper.
2. Use the wrapper around CORS and no-CORS image fetch attempts, with a safe
   no-spoof fallback when DNR is unavailable.
3. Add tests for host matching, cleanup on all outcomes, and unknown-host
   behavior.
4. Run the full extension/backend verification gates.

## Verification

- `npm run verify:repository`
- `npm run build`
- `npm run lint`
- `npm run test:unit -- --runInBand`
- `npm run test:integration -- --runInBand`
- `npm run lint:backend`
- `npm run test:backend`
