# Plan 01-02: Hostname Activation and Toolbar State

## Objective

Give the owner a per-site enable/disable gate without adding accounts or
changing completed translations.

## Tasks

1. Add hostname normalization and local storage helpers with an enabled-by-
   default compatibility behavior and explicit disabled overrides.
2. Gate content-script observer/control startup and command handling on the
   current hostname; refresh safely when storage or popup state changes.
3. Add a popup toggle for the active tab and update the MV3 action title/badge
   per tab.
4. Add tests for hostname state transitions and popup command wiring.

## Verification

- Unit tests cover default enabled, disable, re-enable, and active-tab toggle.
- Manifest/build validation confirms the new shared module is referenced.
